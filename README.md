# Mi Primer Página - Taller Introducción Aplicaciones Web

Este repositorio contiene la solución de la parte práctica y teórica del taller de introducción a las aplicaciones web.

## Parte Teórica

1. **¿Qué es HTML y cuál es su función en la web?**
Es el Lenguaje de Marcado de Hipertexto. Su función es estructurar y dar contenido a las páginas web.

2. **¿Qué es una etiqueta HTML y menciona las etiquetas más comunes?**
Es un código que indica al navegador cómo mostrar los elementos. Ejemplos comunes: `<h1>`, `<p>`, `<a>`, `<img>`.

3. **¿Qué es un atributo de una etiqueta HTML y menciona los más comunes?**
Son propiedades que se añaden a las etiquetas para darles información adicional. Ejemplos: `src`, `href`, `id`, `class`.

4. **¿Qué es CSS y cómo se utiliza para el diseño web?**
Es el Lenguaje de Hojas de Estilo en Cascada. Se utiliza para estilizar, dar colores, tipografías y organizar el diseño visual de la web.

5. **¿Qué es una propiedad en CSS y menciona las propiedades más comunes?**
Es la característica que se modifica de un elemento. Ejemplos: `background-color`, `font-size`, `color`, `text-align`.

6. **¿Qué es un selector en CSS y cuáles tipos existen?**
Es el que apunta al elemento HTML que se va a estilizar. Existen selectores de etiqueta, de clase y de ID.

7. **¿Qué es JavaScript y cómo añade la interactividad a las páginas web?**
Es un lenguaje de programación que permite añadir lógica, dinamismo y reaccionar a acciones del usuario (como clics).

8. **¿Cuáles son los tipos de datos primitivos en JavaScript?**
String (texto), Number (números), Boolean (verdadero/falso), Undefined y Null.

9. **¿Cómo funcionan las estructuras de control de flujo como if, else, switch y bucles en JavaScript?**
Permiten tomar decisiones lógicas o repetir tareas de código según se cumpla o no una condición.

10. **¿Por qué es importante usar nombres significativos para variables y métodos?**
Para que el código sea legible, claro y fácil de entender por cualquier persona que lo lea.

11. **¿Qué es una variable de entorno y por qué son importantes para JavaScript o la programación en general?**
Son valores externos a la aplicación (como credenciales o configuraciones) que protegen información sensible y cambian según el entorno.

12. **¿Qué son las herramientas de desarrollo de Chrome y cómo se accede a ellas?**
Son herramientas integradas en Google Chrome para desarrolladores. Se accede presionando `F12` o haciendo clic en "Inspeccionar".

13. **¿Qué se puede hacer en el panel "Elements" de las herramientas de desarrollo?**
Ver, analizar y modificar en tiempo real el código HTML y los estilos CSS.

14. **¿Cómo se utiliza el panel "Console" de las herramientas de desarrollo y para qué es útil?**
Permite ver errores, advertencias y ejecutar o probar código de JavaScript (como el `console.log()` del botón).

15. **¿Qué información se puede obtener del panel "Network" y por qué es importante?**
Muestra todas las peticiones de red y archivos descargados, útil para medir el rendimiento y velocidad de carga de la web.
